About glances-rs

v0.4.0 pure std + core + alloc + libc no crates.io WIP

glances-rs is a from-scratch Rust reimplementation of Glances, the cross-platform system monitor by Nicolas Hennion. The goal is full feature parity with the Python original while guaranteeing a zero-supply-chain binary: the only code that runs is what we wrote ourselves plus the Rust standard library and the host platform's libc / Win32 / Mach APIs.

Why

Python Glances has roughly 100 third-party dependencies (psutil, fastapi, uvicorn, influxdb-client, paho-mqtt, pysnmp, docker, kafka-python, requests, and ~90 more). Every one of those is a supply-chain attack surface. glances-rs has none of them: it depends only on std, core, alloc, and direct extern "C" FFI calls to libc (Linux/macOS) or kernel32.dll (Windows).

As a side effect, glances-rs produces a single statically-linked binary with no runtime Python, no virtualenv, no pip install. Drop it on a host and it runs.

Hard constraints

  1. No [dependencies] in Cargo.toml — enforced by qa/lint/no_crates.rs as part of cargo test.
  2. Every .rs file ≤ 256 lines — enforced by qa/lint/line_cap.rs. Comments and blank lines count.
  3. No unsafe outside src/platform/{linux,macos,windows}/ and src/exec/safe_run.rs — enforced by qa/lint/unsafe_allowlist.rs.
  4. No shell expansion — every subprocess call uses std::process::Command with explicit argv. Lint fails on sh -c, bash -c, cmd.exe /C.
  5. No path concatenation via format strings — every path is built with std::path::PathBuf::join.

Status

As of v0.4.0:

  • ✅ Skeleton, CLI parser, config + password loading
  • ✅ 8 Linux platform primitives (/proc/stat, /proc/meminfo, /proc/loadavg, /proc/uptime, /proc/net/dev, /proc/diskstats, /sys/class/net, /sys/class/hwmon)
  • ✅ 7 core plugins (cpu, mem, memswap, load, uptime, now, system) — reading live /proc on Linux
  • ⏳ macOS / Windows primitives (cfg-gated stubs; FFI in followup)
  • ⏳ 33 more plugins (percpu, network, processes, sensors, docker, …)
  • ⏳ 24 exporters (CSV, JSON, Prometheus, InfluxDB, Kafka, MQTT, …)
  • ⏳ HTTP/1.1 server + REST API + Vue UI serving
  • ⏳ Curses TUI + browser + XML-RPC + MCP

191 tests pass; see README.md.

How it's built

git clone https://github.com/UberMetroid/glances.git
cd glances && git checkout Rust
cd rust-port
cargo build --release
cargo test

The Rust branch is where all port work happens. The original Python glances/ package is preserved as glances-py/ for reference and will be removed once M15 lands.
