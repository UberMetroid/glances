glances-rs · v0.9.1

A pure-stdlib Rust port of Glances.

glances-rs is a from-scratch Rust reimplementation of Glances, the cross-platform system monitor. CPU, memory, network, disk, processes, exporters, REST API — all built on std, core, and alloc alone. Zero crates.io dependencies. One static binary.

01Why pure stdlib?

Most Rust binaries pull in dozens of crates. glances-rs pulls in none. Every line of platform integration is a direct extern "C" call to libc, Win32, or Mach, or a hand-rolled parser of /proc and /sys. The result:

  • No supply-chain attack surface. There is no transitive dependency graph to audit, patch, or get compromised by typosquatting.
  • Deterministic linking. The same source tree always produces the same binary. No yanked crates, no registry outages, no MSRVC drift.
  • Single static binary. Strip, LTO, codegen-units = 1. Drop the executable on a server and run it.
  • Auditable surface. Every line of unsafe lives under src/platform/linux/ — enforced by lint, not by convention.

02Project history

The full changelog lives on GitHub Releases. The current release is v0.9.1 — the same version pinned in Cargo.toml and surfaced by glances-rs --version.

03Quick start

Build:

cargo build --release

Show the full CLI surface (same flag set as upstream Python Glances):

./target/release/glances-rs --help

Launch the HTTP server on the default port 61208:

./target/release/glances-rs --web

The web mode serves the REST API and the Vue browser UI on http://localhost:61208. Auth is read from the configured password file; the server speaks HTTP/1.1 with chunked SSE for live stats push.
